Остринка

Генератор коротких комиксов для сообщества ВКонтакте

Приложение автоматически создаёт короткие юмористические комиксы и публикует их на стене сообщества «Остринка», которым владеет автор приложения. Оно не собирает данные пользователей и работает только с одним сообществом — тем, где установлено.

Как это работает

  1. Выбирается бытовая тема — поход в магазин, соседи, ремонт, готовка.
  2. Языковая модель придумывает несколько вариантов шутки из трёх кадров, а отдельная проверка выбирает самый удачный.
  3. Генератор изображений рисует комикс, реплики наносятся отдельно, чтобы русский текст всегда был написан правильно.
  4. Готовый комикс публикуется на стене сообщества.

Какие данные использует

  • Публикует записи на стене одного сообщества — того, которым владеет автор.
  • Загружает собственные сгенерированные изображения для этих записей.
  • Не читает переписку, не собирает и не хранит данные пользователей ВКонтакте.

Кто использует

Личный некоммерческий проект одного автора. Приложение не рассчитано на сторонних пользователей: оно обслуживает только сообщество своего владельца.
